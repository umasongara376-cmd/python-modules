# Python Modules Practice

A small collection of Jupyter notebooks for practicing Python standard-library modules.

## Notebooks

- `os module.ipynb` — examples using the `os` module for interacting with the operating system.
- `random.ipynb` — examples using Python's `random` module.
- `time module.ipynb` — examples using the `time` module.

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab

Install and launch Jupyter if needed:

```bash
python -m pip install notebook
jupyter notebook
```

Open a notebook and execute its cells from top to bottom. Some examples may behave differently depending on the operating system or current time.

## Learning Approach

Use the notebooks as focused demonstrations: read the code, run each cell, change the inputs, and observe the results. Avoid running file-system examples on important folders unless you understand the operation they perform.
